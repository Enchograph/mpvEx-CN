# mpvEx-CN v1.3.3（同步上游 v1.3.1）

## 版本说明

- GitHub Tag：v1.0.8（仅用于仓库内区分版本）
- 汉化版 APP 实际版本号：1.3.3（可覆盖安装）
- 上游官方版本：1.3.1

---

## 更新内容（同步上游 v1.3.1）

本次上游只有 **1 个提交**（`2afbe2f`），改动 4 个文件，核心是把播放内核换成官方发布的版本。

### 播放内核
- **mpv-android 升级到官方 1.0.0**：从仓库内置的本地 AAR 改为 Maven Central 官方包
  （`io.github.marlboro-advance:mpv-android:1.0.0`），以后跟随官方统一维护
- **字幕动态系统字体**：原生字幕渲染支持按 fontconfig 动态回退到系统自带字体
  （Roboto / Noto Sans / Noto Serif），不再依赖应用内置字体
- **修复内存泄漏**：`BaseMPVView` 的 Context 生命周期改为正确解析，
  转屏、退出播放器后不再残留 Activity 引用
- **按键映射兼容**：库内按键表由 `KeyMapping` 改名为 `keyMapping`（破坏性改名），
  播放器代码已同步跟随，实体按键、遥控器、外接键盘操作保持原样

### 仓库与构建
- 删除随仓库携带的 **77.6MB** 本地二进制 `app/libs/mpv-android-lib-v0.0.1.aar`
- 同时清理早已无引用、同样占 **68.4MB** 的 `app/libs/mpv-android-lib-v0.0.3.aar`
  （该文件是旧版遗留，并非官方 1.0.0，两者相差 37 个 class，不能混用）
- 仓库体积因此减少约 **146MB**
- 副作用：首次构建需要联网拉取约 68MB 的官方 AAR；本机已配置
  `127.0.0.1:10808` 代理与阿里云镜像，拉取后进入 Gradle 缓存，之后可离线构建

## 汉化版说明

- 上游本次改动**不含任何界面文案**，所以升级本身没有新增英文
- 另按用户反馈补修了两处历史遗留的漏汉化（枚举名被直接当作文案渲染）：
  - 「播放器布局 → 进度条样式」的选项：`Standard / Wavy / Thick` → **标准 / 波浪 / 加粗**
  - 「解码器 → 去色带」的选项与摘要：`None` → **无**（`CPU` / `GPU` 是通用技术术语，保留原样）
- 已复核本次改动的播放器按键文件：其中英文字符串全部是 mpv 属性名/取值
  （`glsl-shaders`、`sub-font`、`hwdec` 等）与协议命令，按约定**不翻译**
- 移除捐赠相关模块
- 禁用自动更新

## 安装说明

- 近几年绝大多数手机请装 **arm64-v8a**
- 只有较老的 32 位设备才需要 **armeabi-v7a**
- 可直接覆盖安装 1.3.2 及之前由同一签名发布的版本；若提示签名不一致，请先卸载旧版再装
- 请勿使用应用内的「检查更新」，升级后会丢失汉化
